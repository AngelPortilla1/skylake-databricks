## Registro cronológico de hallazgos adicionales

- **2026-11-05 (`SKY-003` — Integración de GitHub en Databricks Free Edition):** Al intentar hacer `Commit & Push` desde un Git folder en Databricks usando una cuenta vinculada de GitHub, el push falla con *"El enlace a tu cuenta de GitHub no tiene acceso"* hasta que se instala y autoriza explícitamente la **Databricks GitHub App** sobre el repositorio `skylake-databricks` (o se selecciona explícitamente el Fine-grained PAT con permiso `Contents: Read and write` en la pestaña *Settings* del Git folder).
- **2026-11-05 (`SKY-004` — Creación de catálogo propio `skylake` en Unity Catalog):** `CREATE CATALOG IF NOT EXISTS skylake` ejecutado en el `Serverless Starter Warehouse` (2X-Small) funcionó directamente usando el almacenamiento gestionado por defecto del metastore en Free Edition, sin necesidad de recurrir al catálogo `workspace` por defecto.
- **2026-11-10 (`SKY-006` — Diferencia entre Workspace Groups y Account Groups en Unity Catalog):** En Databricks Free Edition sin consola de cuenta dedicada, el comando `databricks groups create` crea grupos locales del workspace (`/api/2.0/preview/scim/v2/Groups`) que fallan al usarse en sentencias `GRANT ... TO <grupo>` de Unity Catalog con `PRINCIPAL_DOES_NOT_EXIST`. Para usar grupos en `GRANT` de Unity Catalog es obligatorio crearlos como **grupos de cuenta** mediante `/api/2.0/account/scim/v2/Groups` (o en la pestaña *Account groups* de `Settings -> Identity and access -> Groups`).
- **2026-11-10 (`SKY-006` — Subdirectorios en Volumes con `databricks fs cp`):** El comando `databricks fs cp archivo.json dbfs:/Volumes/skylake/bronze/landing/subcarpeta/archivo.json` falla con `no such directory` si `subcarpeta` no existe previamente (requiere `databricks fs mkdirs`), mientras que `WorkspaceClient().files.upload()` del SDK de Python crea las rutas intermedias automáticamente.
